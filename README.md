# Ejection Fraction on a Budget

Accuracy-versus-compute study of video models for ejection fraction
estimation on EchoNet-Dynamic. Output: a cost–accuracy Pareto frontier with
clinical error stratification at every operating point, all 22
configurations trained under one fixed recipe and profiled under one frozen
cost protocol.

## Layout

```
src/          library: dataset, backbones, training, evaluation, cost harness
configs/      one YAML per training run (30 runs)
scripts/      sweep drivers (stages 3a/3b/3d) and result analysis
figures/      figure scripts; rendered output in figures/out/
results/      run registry, cost profiles, per-video predictions, metrics
tests/        pipeline tests on a synthetic mini-dataset (no real data needed)
docs/         study plan, frozen cost protocol, environment record
```

## Setup

See `docs/ENVIRONMENT.md`. Data: register individually at
[echonet.github.io/dynamic](https://echonet.github.io/dynamic), download via
Redivis to a local `data/EchoNet-Dynamic/` (never committed, never mirrored).

## Workflow

```bash
# once: train-set normalization stats
python -m src.data data/EchoNet-Dynamic

# single run: train -> predict -> report -> cost
python -m src.train configs/3a_r2p1d_f32_p2.yaml --data data/EchoNet-Dynamic
python -m src.evaluate predict configs/3a_r2p1d_f32_p2.yaml \
    checkpoints/3a_r2p1d_f32_p2/best.pt --data data/EchoNet-Dynamic \
    --out results/metrics/3a_r2p1d_f32_p2.pred.csv
python -m src.evaluate report results/metrics/3a_r2p1d_f32_p2.pred.csv \
    --out results/metrics/3a_r2p1d_f32_p2.metrics.json
python -m src.cost configs/3a_r2p1d_f32_p2.yaml --data data/EchoNet-Dynamic

# full sweeps (unattended; commit results per run)
python scripts/sweep_3a.py          # 12 clip-geometry configs
python scripts/sweep_3b.py          # 6 alternative backbones
python scripts/sweep_3b_x3d.py      # 4 X3D configs (memory probe + train)
python scripts/sweep_3d_seeds.py    # 8 seed replicates

# analysis and figures (run after the sweep)
python scripts/analyze_all.py       # summary, comparisons, seed tables
python figures/plot_frontier.py     # cost-accuracy frontiers
python figures/plot_clinical.py     # error by EF band + Bland-Altman
python figures/plot_scatter.py      # predicted vs reference EF
```

`scripts/run_sweep.ps1 -Data data\EchoNet-Dynamic` walks `configs/`
cheapest-first through the same per-run pipeline, skipping completed runs —
safe to re-run after any interruption.

## Repo contract

- `results/registry.csv` — one row per training run (auto-appended)
- `results/costs.csv` — one row per config, single tagged cost protocol
  (`docs/PROTOCOL.md`)
- `results/metrics/` — per-config per-video predictions + bootstrapped metrics
- `figures/out/` — generated by script only, never edited by hand
- No videos, frames, or derived imagery are ever committed (Stanford
  agreement)
